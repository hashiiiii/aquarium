# 企画書: モンスター撮影 × 放置 × 効率化ゲーム

## コンセプト

「**撮って、並べて、効率を極める**」

ダンジョンでモンスターを撮影して集め、最適な編成で放置生産の効率を追求するゲーム。

## 制約

- 運営型スマホゲーム
- 1日の拘束時間: 30 分
- 運用工数の最小化 (アセット制作コストを抑える)

## コアループ

```
撮影 → 編成・配置 → 放置 → 資源活用 → (ループ)
```

### 1. 撮影

- ダンジョンでモンスターを発見し、カメラで撮影して入手
- 同じモンスターでも撮影ごとに「個体値」と「スキル」がランダム決定
- 放置によって得られた資源を活用することで個体値にボーナス

### 2. 編成・配置

- 入手したモンスターを拠点に配置
- 配置によりシナジーが発生 (例: 火属性3体で全体効率 + 50%)
- どのモンスターをどこに置くかで効率が大きく変わる → パズル的思考

### 3. 放置

- 配置したモンスターが自動で資源を生産
- 生産効率 = 基礎値 × 個体値 × スキル補正 × 配置ボーナス × 施設レベル

### 4. 資源活用

| 用途 | 効果 |
|------|------|
| 新ダンジョン解放 | 新モンスターが撮影可能に |
| 撮影機材強化 | 高個体値の出現確率UP |
| 施設拡張 | 配置枠増加、放置効率UP |
| モンスター合成 | 低個体値を素材に高個体値を強化 |

## 楽しさの核

| 要素 | 体験 |
|------|------|
| 撮影・厳選 | 射幸心、コレクション欲 |
| 編成最適化 | 効率を極める工業化の楽しさ |
| 放置 → 回収 | 成長実感、ログイン動機 |
| 数字のインフレ | 「昨日より強くなった」感 |

## エンドコンテンツ

### プレステージ（転生）システム

- 全モンスター・資源をリセット
- 代わりに「転生ボーナス」を獲得 (全効率+10%, +25%, +50%...)
- 「いつ転生するか」が新たな最適化問題になる
- 2周目以降は前周より速く進む快感

### 週替わりルール

- 毎週、特定属性の生産量にボーナス (例: 水属性 x3)
- 普段使わないモンスターに価値が出る
- 手持ちの多様性が重要 → 廃課金が必ずしも勝てない

### ランキング

- 週次 / 月次の生産量ランキング
- 条件付きランキング (属性縛りなど)

## 1日のプレイサイクル

```
【ログイン】20分

1. 放置結果確認・資源回収 (1分)

2. ダンジョン探索・撮影 (10分)
   - スタミナ分を消化
   - 高個体値を狙う

3. 編成調整 (5分)
   - 新モンスターを配置
   - 効率シミュレーション
   - 合成判断

4. ログアウト → 放置開始
```

## 運用設計

| コンテンツ | 更新頻度 | 工数 |
|-----------|---------|------|
| 新モンスター | 月2-4体 | 低 |
| 週替わりルール | 毎週 | 極低 |
| イベントダンジョン | 月1-2回 | 中 |
| 新エリア | 3-6ヶ月 | 高 |

## 体験デザイン（参考: 「ついやってしまう」体験のつくりかた）

### 直感のデザイン

- 「このダンジョンにはこのモンスターがいそう」→ 図鑑のシルエット表示

### 驚きのデザイン

- 超低確率で伝説モンスター出現
- 予想外のシナジー発見
- 転生後の成長速度の違い

### 物語のデザイン

- モンスター図鑑にストーリー断片
- 収集を進めると世界観が見えてくる
