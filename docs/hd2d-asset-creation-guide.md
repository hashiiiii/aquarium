# HD-2D アクアリウム/テラリウムゲーム アセット制作ガイド

## 概要

本ドキュメントでは、オクトパストラベラーのようなHD-2Dスタイルのアクアリウム/テラリウムゲームを制作するための、ドット絵アセット作成手順をまとめます。

## HD-2Dとは

HD-2Dは、3Dの環境にドット絵（ピクセルアート）テクスチャを組み合わせる手法です。

**特徴：**
- 3Dオブジェクトにドット絵テクスチャを貼り付ける
- 2Dドット絵キャラクターを3D空間に配置
- 被写界深度、ボリュームライト、パーティクルなどの3Dエフェクトを追加
- レトロなドット絵の魅力と現代的な表現力の融合

**ユーザーの理解について：**
> 「3DのオブジェクトをUnity上で作って、それにテクスチャを貼り付けていくようなイメージ」

→ **正しい理解です。** Unity上で3Dメッシュを作成し、ドット絵テクスチャをマテリアルとして適用します。

## 使用ツール

### 1. Pixellab.ai
AI を使用してゲーム用ドット絵を高速生成するツール。

**主な機能：**
- テキストプロンプトからドット絵生成
- ワンクリックアニメーション生成
- 4方向・8方向キャラクター自動生成
- テクスチャ・タイルセット生成
- スタイル一貫性を保った編集（インペイント）

**用途：**
- キャラクター（魚、サンゴ、植物など）の初期デザイン
- 背景テクスチャの生成
- アニメーションスプライトの作成

### 2. SpriteFusion Pixel Snapper
AI生成ドット絵をグリッドに整列させる後処理ツール。

**解決する問題：**
- ピクセルサイズ・位置の不均一
- グリッド解像度のズレ
- カラーパレットの不統一

**用途：**
- Pixellab.aiで生成した画像のクリーンアップ
- テクスチャのシームレス化
- カラーパレットの統一

## ミニマム実装手順

### Phase 1: キャラクター（魚）のドット絵作成

#### Step 1.1: Pixellab.ai でベース画像を生成

1. [Pixellab.ai](https://www.pixellab.ai/) にアクセス
2. 無料トライアルでアカウント作成
3. プロンプト例：
   ```
   pixel art tropical fish, side view, 32x32, vibrant colors, game sprite
   ```
4. 複数バリエーションを生成
5. 気に入ったものをダウンロード

#### Step 1.2: アニメーション作成（オプション）

1. Pixellab.ai のアニメーション機能を使用
2. 泳ぎモーション用のスプライトシートを生成
3. 4〜8フレームの遊泳アニメーションを作成

#### Step 1.3: Pixel Snapper で整列・調整

1. [SpriteFusion Pixel Snapper](https://spritefusion.com/pixel-snapper) にアクセス
2. 生成した画像をアップロード
3. グリッドサイズを設定（例：32x32）
4. カラーパレットを指定（オプション）
5. 整列済み画像をダウンロード

### Phase 2: 3Dオブジェクト用テクスチャ作成

#### Step 2.1: 必要なテクスチャの洗い出し

アクアリウムの基本構成要素：
- 水槽の壁面テクスチャ
- 砂/砂利テクスチャ
- 岩テクスチャ
- 水草テクスチャ
- サンゴテクスチャ
- 装飾品テクスチャ

#### Step 2.2: Pixellab.ai でテクスチャ生成

1. タイルセット/テクスチャ生成モードを使用
2. プロンプト例：
   ```
   pixel art seamless sand texture, underwater, 64x64, tileable
   ```
   ```
   pixel art coral reef texture, colorful, game asset, seamless
   ```
3. シームレス（繰り返し可能）なテクスチャを生成

#### Step 2.3: テクスチャの後処理

1. Pixel Snapper でグリッド整列
2. 画像編集ソフト（GIMP, Aseprite等）でシームレス確認・調整
3. Unity用に適切な解像度で書き出し（64x64, 128x128, 256x256など）

### Phase 3: Unity での組み込み準備

#### Step 3.1: フォルダ構成

```
Assets/
├── Sprites/
│   ├── Characters/
│   │   └── Fish/
│   └── UI/
├── Textures/
│   ├── Environment/
│   │   ├── Sand/
│   │   ├── Rock/
│   │   └── Coral/
│   └── Props/
└── Materials/
    └── HD2D/
```

#### Step 3.2: テクスチャインポート設定

Unity でドット絵テクスチャを綺麗に表示するための設定：

| 設定項目 | 推奨値 |
|---------|-------|
| Filter Mode | Point (no filter) |
| Compression | None |
| Pixels Per Unit | テクスチャサイズに応じて調整 |
| Wrap Mode | Repeat（タイルテクスチャの場合） |

#### Step 3.3: マテリアル設定

1. 新規マテリアルを作成
2. シェーダー：`Unlit/Texture` または カスタムHD-2Dシェーダー
3. ドット絵テクスチャをアサイン
4. 3Dオブジェクトに適用

## 推奨解像度ガイドライン

| アセット種類 | 推奨サイズ | 備考 |
|------------|----------|------|
| キャラクター（小） | 16x16 〜 32x32 | 小魚、エビなど |
| キャラクター（中） | 32x32 〜 64x64 | 熱帯魚、カメなど |
| キャラクター（大） | 64x64 〜 128x128 | 大型魚、特殊キャラ |
| 環境テクスチャ | 64x64 〜 256x256 | タイル可能に |
| 装飾品 | 32x32 〜 64x64 | 個別オブジェクト用 |
